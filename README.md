# DieuSoms

An ongoing e-commerce web application built with React and Vite.

[![Live Demo](https://img.shields.io/badge/Live-Demo-brightgreen)](https://dieu-soms.vercel.app)
![React](https://img.shields.io/badge/React-18-blue)
![Vite](https://img.shields.io/badge/Built_with-Vite-646CFF)

## Features

- Product browsing and listing pages
- React-based routing and state management
- Responsive layout for mobile and desktop
- Ongoing development — new features added regularly

## Stack

- React
- Vite
- JavaScript (ES6+)

## Run locally

```bash
git clone https://github.com/daniel-fechi/dieuSoms.git
cd dieuSoms
npm install
npm run dev
```
